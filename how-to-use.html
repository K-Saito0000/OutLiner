OutLiner の使い方

画像からレーザーカッター・UVプリンター用の加工データをつくる

アプリを開く →

このツールでできること

画像から不要な背景を取り除いてオブジェクトを切り出し、そのまま加工機用のデータを書き出します。処理はすべてブラウザの中で完結し、画像がサーバーへ送られることはありません。

画像を読み込む → 切り抜く → 色を調整（任意） → 切り出して書き出す

書き出せるのは次の3種類です。3つとも同じキャンバスサイズで出力されるので、重ねても位置がずれません。

出力用途形式
カラーPNG通常の切り出し画像・UVプリントのカラー版透明背景つきPNG
白版PNGUVプリンターの白インキ層白ベタPNG
輪郭SVGレーザーカッターのカットパス赤線のベクターSVG（px単位）

1はじめかた

ブラウザで開く

公開ページをそのまま開けば使えます。インストールは不要です。

https://k-saito0000.github.io/OutLiner/

手元のファイルから使う場合

リポジトリを取得して、フォルダ内でローカルサーバーを立ち上げてください。

python3 -m http.server 8784

起動したら http://localhost:8784/ を開きます。

写真モードを使うときは注意
AI切り抜きのモデルを読み込む都合上、写真モードは http:// または https:// で開いた場合のみ動作します。outliner.html をダブルクリックして開いた（file://）状態では、透過PNGモードだけが使えます。

入力タイプを選ぶ

画面上部のトグルで、読み込む画像の種類を選びます。

選択こんなときに対応形式
透過PNGすでに背景が透明になっている画像（イラスト、書き出し済みのロゴなど）PNG
写真・画像（AI切り抜き）背景が写り込んでいる写真や画像PNG / JPEG / WebP

2透過PNGモード

透明部分を手がかりにオブジェクトを自動で見つけて切り出します。

  1. 「透過PNG」を選んで、PNGをドラッグ＆ドロップします。
  2. プレビュー左側に、見つかったオブジェクトが番号付きの枠で表示されます。
  3. 切り出したくないオブジェクトはクリックで選択を外せます（枠が破線・グレーになります）。
  4. 右側の「切り出しモード」で、まとめて1枚にするか、オブジェクトごとに分けるかを選びます。

切り出しモード

モード動作
全体トリミング選択中のオブジェクトすべてを含む最小の四角形で、1枚に切り出します。
個別切り出しオブジェクトごとに別ファイルとして切り出します。四角形の中に他のオブジェクトが重なっていても、その部分は透明にして混入を防ぎます。
うっすら残るゴミが混ざるときは「アルファ閾値」を少し上げてください。半透明のノイズを背景として無視するようになります。

3写真モード（AI切り抜き）

写真から被写体をAIが自動で切り抜きます。うまくいかなかったところは、あとから手で直せます。

  1. 「写真・画像（AI切り抜き）」を選んで、写真をドラッグ＆ドロップします。
  2. 初回だけモデルの読み込みで少し待ちます（2回目以降はブラウザにキャッシュされます）。
  3. 切り抜き結果が表示されます。赤くなっている部分が切り落とされる背景です。
  4. 必要に応じて調整し、「減色へ進む」または「減色をスキップして切り出しへ」を押します。

マスク閾値

残す範囲の広さを調整します。下げると広く残り、上げると狭くなります。動かしても推論はやり直さないので、すぐに結果が変わります。

ブラシで手直し

ツール動作
けすなぞったところを背景（切り落とす側）にします。
たすなぞったところを残す側にします。

塗りはなぞり終わったときに反映されます。なぞっている間は、けす＝赤・たす＝緑の円で範囲が表示されます。

にた色モード（既定ON）をONにしておくと、なぞった場所の近くにある似た色の範囲まで自動で切り替わります。背景をざっくりなぞるだけで一気に消せるので、細かくなぞる手間が減ります。
輪郭ぎりぎりを慎重に直したいときはOFFにしてください。なぞった円の中だけが変わります。

やり直したいときは「元に戻す」「やり直す」を使ってください（20回分まで戻せます）。AIの結果からやり直したいときは「AI切り抜きをやり直す」を押します。

4減色と色の調整

写真の色数を減らして、UVプリントのインキ層分けやレーザー彫刻の段階分けに使いやすくします。減色が不要ならスキップできます。

色数

2〜8色から選びます（既定4色）。「減色しない」を選べば元の色のままにできます。

範囲を指定して、その部分だけ色の扱いを変える

顔まわりだけ元の色で残したい、模様だけ1色にまとめたい、といった調整ができます。まず範囲の指定方法を選び、次にその範囲の色をどう扱うかを選んでから、プレビュー上で指定します。

範囲の指定方法動作
クリッククリックした場所から、似た色の範囲を自動で選びます。目や鼻などのピンポイント指定に。
ブラシなぞって範囲を選びます。広い範囲や複数の場所をまとめて指定できます。「にた色まで広げる」をONにすると、なぞった色に似た周囲まで自動で含めます。
指定した範囲の色動作使いどころ
元画像のままその範囲は減色せず、元画像の色をそのまま再現します。顔まわりだけフルカラーで残したいとき
この範囲だけ細かく減色その範囲だけ多め（6〜32色）の色数で減色します。1色にはまとめないので、毛並みや陰影の質感が残ります。質感は残しつつ、色は整理したいとき
単色にするその範囲を代表色1色で塗ります。目や模様を1色として扱いたいとき

パレットの操作

  • 色を差し替える: 各行のスウォッチ（色見本）をクリックして好きな色に変更できます。
  • 色をまとめる: 行をクリックして2色以上選ぶと、「どの色にまとめますか？」が表示されます。まとめ先を選ぶと1色として扱われます。「まとめをぜんぶもどす」で解除できます。
  • 各行の％は、その色が占める面積の割合です。インキの使用量や版の面積の目安になります。
  • 「色調整をリセット」で、差し替え・まとめ・範囲指定をすべて初期状態に戻せます。
行ったり来たりできます。「切り抜き」「減色」「切り出し」は自由に往復できます。切り出し画面の「← 切り抜きへ戻る」「← 減色へ戻る」から戻っても、マスクや色の設定は保持されます。

5切り出しと書き出し

プレビューの見かた

左が元画像（検出結果つき）、右が切り出し結果です。右側ではカラーPNG・白版PNG・輪郭SVGを重ねて確認できます。

  • チェックボックスで各レイヤーの表示／非表示を切り替えます。
  • スライダーで不透明度を変えられます（白版を半透明にすると、下のカラーとの重なり具合がわかります）。
  • ▲▼で前後の重なり順を入れ替えられます（上の行ほど手前）。

調整パラメータ

項目内容
アルファ閾値どこまでを背景とみなすか。半透明のゴミを消したいときに上げます。
余白パディング切り出しの周囲に残す余白（px）。
白版の収縮／拡張プラス＝チョーク（輪郭より小さく／印刷ズレで白がはみ出すのを防ぐ）、マイナス＝スプレッド（輪郭より大きく／下地の白をはみ出させる）。
輪郭のオフセットプラス＝外側（オブジェクトから離してカット）、マイナス＝内側（食い込ませてカット）。
白版を拡張したり輪郭を外側にずらしたりすると、その分だけ切り出し範囲が自動的に広がります（3つの出力すべてで同じだけ広がります）。はみ出して欠けることはなく、重ね合わせのズレも起きません。

保存

「出力タイプ」で書き出したいものを選び、各項目の「保存」を押します。複数ある場合は「すべてダウンロード」でまとめて保存できます。

6加工機に渡すときの注意

レーザーカッター（輪郭SVG）

  • SVGの座標はpx単位です。LightBurnなどに読み込んだら、仕上がりの実寸に合わせて拡大・縮小してください。
  • 線は赤（#ff0000）・塗りなしで書き出しています。機械側でカット線として設定してください。
  • 穴のある形（ドーナツ型など）は、内側の輪郭も含まれます。

UVプリンター（白版PNG＋カラーPNG）

  • 白版とカラーは同じキャンバスサイズなので、そのまま重ねて配置できます。
  • 白がはみ出しやすい場合は「白版の収縮」をプラス側に少し振ってください（1〜3px程度から試すのが安全です）。
  • 入稿データは出力タイプごとに個別に保存してください。プレビューのレイヤー合成は確認用で、合成した画像は書き出されません。

その他

  • 写真モードの作業解像度は長辺1000pxです。それより大きい写真は縮小されます。
  • 一度に処理できるのは1枚です。複数ファイルの一括処理には対応していません。
OutLiner — 画像はすべてブラウザ内で処理され、外部に送信されません。
