# OutLiner

PNGの透明部分（アルファチャンネル）を切り取り、オブジェクトをアウトラインで切り出すWebアプリです。レーザーカッター・UVプリンターでの加工データ作成を想定しています。ブラウザ内で完結し、画像が外部に送信されることはありません。

## How to use

1. このリポジトリをクローンまたはZIPでダウンロードする
2. ローカルサーバーを起動する

   ```bash
   python3 -m http.server 8784
   ```

3. ブラウザで http://localhost:8784/outliner.html を開く
4. アルファチャンネル付きPNGをドラッグ＆ドロップする
5. モード・出力タイプ・調整値を設定し、「保存」でダウンロードする

※ `outliner.html` をダブルクリック（`file://` で開く）でも動作します。

## 機能

### オブジェクト検出
- アルファ値の連結成分ラベリング（8近傍）でオブジェクトを自動検出
- プレビュー上でクリックして切り出し対象を選択／解除
- 微小ノイズ（4px未満）は自動除外

### 切り出しモード
| モード | 内容 |
|---|---|
| 全体トリミング | 選択オブジェクト全体を含む最小矩形で1枚に切り出し |
| 個別切り出し | オブジェクトごとに個別ファイルとして切り出し（他オブジェクトの重なりは透明化） |

### 出力タイプ（3タイプとも同一キャンバスサイズで出力・重ね合わせズレなし）
| タイプ | 用途 | 形式 |
|---|---|---|
| カラーPNG | 通常の切り出し画像 | 透明背景PNG |
| 白版PNG | UVプリンターの白インキレイヤー | 白ベタPNG |
| 輪郭SVG | レーザーカッターのカットパス | 赤線ベクターSVG（px単位） |

### 調整
- **アルファ閾値**: 半透明ピクセルをどこまで背景とみなすか（うっすら残るゴミの除去）
- **余白パディング**: 切り出し後の周囲余白（px）
- **白版の収縮／拡張**: プラス＝チョーク（白のはみ出し防止）／マイナス＝スプレッド（下地の白を輪郭より広く）。拡張時は切り出し範囲が全タイプ共通で自動拡大
- **輪郭のオフセット**: プラス＝外側（オブジェクトから離してカット）／マイナス＝内側（食い込ませてカット）。外側オフセット時も切り出し範囲が自動拡大

### プレビュー
- 左に元画像（検出結果のオーバーレイつき）、右に切り出し結果を表示
- 切り出し結果はカラー／白版／輪郭をレイヤーとして重ねて表示可能（表示ON/OFF・不透明度・▲▼で順序入れ替え）

## 注意

- SVGはpx単位です。レーザーカッターのソフトに取り込む際は実寸に合わせてスケールしてください
- 入稿データは出力タイプごとに個別保存してください（レイヤー合成はプレビュー確認用です）
